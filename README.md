# Карточки

Приложение для изучения языков карточками с умным повторением.

- Курсы: английский, русский, немецкий, китайский, корейский
- Повторение по шкале 1 / 2 / 5 / 10 / 21 день
- Игры: спринт на время, найди пару, аудирование, тест уровня
- Серия, дневная цель, 30 достижений, статистика, поиск по колодам
- Резервная копия прогресса, ежедневное напоминание (уведомления на Android)

## Структура
- `www/index.html` — всё приложение (разметка, стили и логика)
- `capacitor.config.json` — настройки упаковки в APK
- `.github/workflows/build-apk.yml` — автоматическая сборка APK на GitHub

## Как собирается APK
При каждом изменении в ветке `main` GitHub запускает сборку (вкладка **Actions**).
Готовый файл лежит внизу страницы запуска в разделе **Artifacts** → `kartochki-apk`.
